# Changelog

## 1.0.0 - 2026-11-13

First release.

- `SKILL.md`: writes a "New to this? Start here" section at the top of a README (who it is for, the problem, four steps, one sentence to type, what comes back).
- The output block is only ever from a real run; otherwise the section says `Not run yet`.
- `sample/tiny-wordcount/`: a small project to try the skill on.
- `examples/README-after.md`: the result of a real run of the skill on that sample.
